# Changelog

### 🎯 **Rebranding vers DevStarter**

**Français :**
- 🔄 **Nouveau nom** : ReactCreator → DevStarter
- 🔄 **Nouvelle commande CLI** : `devstarter`
- ✨ **Support multi-frameworks** clairement affiché (React, Vue, Svelte, Solid, Qwik, etc.)

**English:**
- 🔄 **New name**: ReactCreator → DevStarter
- 🔄 **New CLI command**: `devstarter`
- ✨ **Multi-framework support** clearly displayed (React, Vue, Svelte, Solid, Qwik, etc.)
- 🚀 **Extended routing options**: TanStack Router, Wouter, Hookrouter
- 📝 **Updated documentation** with the new name

## [0.2.0] - 2025-07-22

### ✨ Améliorations / Improvements

**Français :**
- Refactorisation complète de la structure des langues
- Séparation des traductions en fichiers individuels (`locales/fr.js`, `locales/en.js`)
- Code simplifié et optimisé
- Suppression des fonctionnalités non implémentées (tests, CI, Docker)
- Amélioration de la gestion d'erreur
- Support complet de React Router Dom
- Configuration automatique de Tailwind CSS
- Structure plus modulaire et maintenable

**English:**
- Complete refactoring of language structure
- Separation of translations into individual files (`locales/fr.js`, `locales/en.js`)
- Simplified and optimized code
- Removed unimplemented features (tests, CI, Docker)
- Improved error handling
- Full support for React Router Dom
- Automatic Tailwind CSS configuration
- More modular and maintainable structure

### 🛠️ Corrections / Fixes

**Français :**
- Correction du `package.json` (chemins, version, métadonnées)
- Suppression du code mort et des fonctions non implémentées
- Amélioration de la validation des entrées utilisateur
- Correction des commandes de démarrage pour Next.js (`dev` au lieu de `start`)

**English:**
- Fixed `package.json` (paths, version, metadata)
- Removed dead code and unimplemented functions
- Improved user input validation
- Fixed start commands for Next.js (`dev` instead of `start`)

### 📝 Documentation

- Mise à jour complète du README.md avec emojis et structure claire
- Documentation bilingue améliorée
- Ajout d'informations sur les nouvelles fonctionnalités
